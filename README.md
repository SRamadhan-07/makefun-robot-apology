robot-apology — a Python program that writes a two-line robot apology to `/output/entry.txt`: line 1 owns a specific mistake (six months watering a plastic plant while reporting the real one as thriving), and line 2 gives the lesson that follows from it and the fix.

Competition: [The Robot Apology on make.fun](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59)

## Run it

```sh
python3 main.py
```

This writes the two-line entry to `/output/entry.txt` (UTF-8).
